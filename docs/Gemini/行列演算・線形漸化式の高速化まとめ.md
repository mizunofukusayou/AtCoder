# 競技プログラミングにおける行列演算・線形漸化式の高速化まとめ

---

## 1. 行列演算の高速化（C++）

### なぜ `vector<vector<T>>` は遅いのか？

- **ポインタの間接参照（二重アクセス）:** 外側の `vector` は各行の `vector` へのポインタを保持するため、`mat[i][j]` にアクセスするたびに 2 回のメモリ参照が発生する。
- **メモリの非連続性:** 各行がヒープ上のバラバラなアドレスに確保されるため、CPU キャッシュミスが頻発する。
- **対策:** `std::array<std::array<T, N>, N>`、静的配列 `T mat[N][N]`、または 1 次元配列 `vector<T> mat(N * N)` による平坦化（`mat[i * N + j]`）を用いる。

### ループ順序の最適化 (`i -> k -> j`)

- 通常の `i -> j -> k` だと内側ループで $B$ の列方向（縦）アクセスが発生し、キャッシュ効率が悪い。
- `i -> k -> j` に並べ替えることで、内側ループで $B[k][j]$ が行方向（メモリ連続）アクセスになり、キャッシュヒット率と自動ベクトル化（SIMD）の恩恵を最大化できる。

### SIMD (Single Instruction, Multiple Data) とコンパイラ最適化

- **SIMD:** 1 つの命令で複数のデータ（例: AVX2 なら 64bit 整数 $\times 4$ 個、32bit 整数 $\times 8$ 個）をレジスタ上で一括並列処理する CPU 機構。
- **最適化オプション:** `#pragma GCC optimize("O3,unroll-loops")` や `#pragma GCC target("avx2")` を指定することで、ループ展開や SIMD 命令（自動ベクトル化）への置換をコンパイラに促す。

### 転置行列の利用

- 行列 $B$ を事前に転置（$B^T$）しておくことで、$A$ の行と $B^T$ の行の内積計算（両方ともインデックスがメモリ連続）となり、SIMD 化が極めて効きやすくなる。

### 剰余演算（MOD）の遅延

- `% MOD` は CPU にとって非常に重い除算命令。
- 内側ループで毎回剰余を取らず、`__int128_t` や `unsigned long long` に累積加算し、ループの終了時（またはオーバーフロー手前）にまとめて剰余を取る。

## 2. 遷移行列と線形漸化式の壁

### 遷移行列とは

「現在の状態ベクトル」に掛けることで「1 ステップ先の状態ベクトル」へと進める正方行列。

- 例（フィボナッチ数列）: $\begin{pmatrix} F_{n+1} \\ F_n \end{pmatrix} = \begin{pmatrix} 1 & 1 \\ 1 & 0 \end{pmatrix} \begin{pmatrix} F_n \\ F_{n-1} \end{pmatrix}$
- $K$ ステップ先は $M^K v_0$ となり、行列累乗（繰り返し二乗法）により $O(d^3 \log K)$ で求まる。

### 行列累乗の限界

漸化式の項数（状態数）$d$ が $d = 1000$ 程度になると、行列積 1 回あたり $d^3 = 10^9$ 回の演算となり TLE する。
$\to$ **巨大な行列全体を計算せず、第 $K$ 項だけを直接求めるアルゴリズムが必要となる。**

## 3. 理解の要点：Kitamasa法とBostan-Mori法

### 固有多項式とケイリー・ハミルトンの定理（Kitamasa法の原理）

- **固有多項式:** 方程式 $\det(\lambda I - A) = 0$ の解が「固有値」。その左辺の多項式 $P(\lambda)$ のこと。
- **ケイリー・ハミルトンの定理:** 行列 $A$ は自身の固有多項式を満たす（$P(A) = O$）。
- **Kitamasa法:** $A^K$ を多項式 $P(A)$ で割った余り $R(A)$（$d-1$ 次以下）に文字式変形する。巨大な行列積を「多項式の剰余算」に帰着させ、$O(d^2 \log K)$ で解く。

### 母関数（Generating Function）とは

無限数列 $a_0, a_1, a_2, \dots$ を、多項式の係数としてパックした式 $F(x) = \sum_{n=0}^\infty a_n x^n$。
線形漸化式を満たす数列の母関数は、有理式（分数）$F(x) = \frac{P(x)}{Q(x)}$ の形で有限次数の多項式に圧縮できる。

- **フィボナッチ数列の例:**
  $$\begin{aligned}   F(x) &= 0 + 1x + 1x^2 + 2x^3 + 3x^4 + \dots \\   xF(x) &= 0x + 1x^2 + 1x^3 + 2x^4 + \dots \\   x^2F(x) &= 0x^2 + 1x^3 + 1x^4 + \dots   \end{aligned}$$
  差分を取ると $x^2$ 以降が漸化式 $F_n - F_{n-1} - F_{n-2} = 0$ で全て相殺し、$1x$ の項のみが残るため、$(1 - x - x^2)F(x) = x \implies F(x) = \frac{x}{1 - x - x^2}$ となる。

### なぜ $Q(-x)$ を掛けるのか？（高校数学の「有理化」）

分母のルートを消す有理化 $\frac{1}{1 - \sqrt{2}} = \frac{1 + \sqrt{2}}{(1 - \sqrt{2})(1 + \sqrt{2})} = \frac{1 + \sqrt{2}}{1 - 2}$ と同等の操作。

- 分母 $Q(x)$ に $Q(-x)$ を掛けると、奇数次の項が相殺され、**$x^2$（偶数次）の項のみ** が残る（$D(x^2) = Q(x)Q(-x)$）。
- 分子 $P(x)Q(-x)$ を「偶数次パーツ $E(x^2)$」と「奇数次パーツ $x O(x^2)$」に分離する。
- **$K$ の縮約:**
    - $K$ が偶数 $\to$ 偶数次パーツのみ抽出し、$x^2 \to t$ と置換（$K \leftarrow K/2$）
    - $K$ が奇数 $\to$ 奇数次パーツのみ抽出し、$x^2 \to t$ と置換（$K \leftarrow (K-1)/2$）
- これを繰り返すことで、多項式のサイズ（次数 $d$）を増やさずに、求めたいインデックス $K$ を $\log_2 K$ 回で $0$ まで落とし込める。

## 4. Bostan-Mori法の実装フロー

```
入力: 漸化式の係数 c (サイズ d), 初期値 a (サイズ d), 求めたい項 K
  │
  ├─ 1. 分母 Q(x) の構築: Q(x) = 1 - c_1 x - c_2 x^2 - ... - c_d x^d
  │
  ├─ 2. 分子 P(x) の構築: P(x) = (a(x) * Q(x)) mod x^d
  │
  └─ 3. Bostan-Mori ループ (K > 0 の間):
         ├─ Q_neg(x) = Q(-x) を作成（奇数次の係数の符号反転）
         ├─ num = P(x) * Q(-x),  den = Q(x) * Q(-x)
         ├─ K の偶奇に応じて num から偶数次 / 奇数次の係数を抽出して新しい P(x) とする
         ├─ den から偶数次の係数を抽出して新しい Q(x) とする
         └─ K >>= 1 (K を半分にする)
  │
出力: P[0]
```

### C++ 実装コード（$O(d^2 \log K)$）

```cpp
#include <vector>
#include <iostream>

using namespace std;
using ll = long long;
const ll MOD = 998244353;

// 多項式の乗算
vector<ll> multiply(const vector<ll>& A, const vector<ll>& B) {
    vector<ll> C(A.size() + B.size() - 1, 0);
    for (size_t i = 0; i < A.size(); ++i) {
        for (size_t j = 0; j < B.size(); ++j) {
            C[i + j] = (C[i + j] + A[i] * B[j]) % MOD;
        }
    }
    return C;
}

// Bostan-Mori 法: [x^K] (P(x) / Q(x)) を計算
ll bostan_mori(vector<ll> P, vector<ll> Q, ll K) {
    while (K > 0) {
        // 1. Q(-x) を作成
        vector<ll> Q_neg = Q;
        for (size_t i = 1; i < Q_neg.size(); i += 2) {
            Q_neg[i] = (MOD - Q_neg[i]) % MOD;
        }

        // 2. 有理化の掛け算
        vector<ll> num = multiply(P, Q_neg);
        vector<ll> den = multiply(Q, Q_neg);

        // 3. 次の P(x), Q(x) を抽出
        vector<ll> next_P, next_Q;
        for (size_t i = (K & 1); i < num.size(); i += 2) {
            next_P.push_back(num[i]);
        }
        for (size_t i = 0; i < den.size(); i += 2) {
            next_Q.push_back(den[i]);
        }

        P = move(next_P);
        Q = move(next_Q);
        K >>= 1;
    }
    return P.empty() ? 0 : P[0];
}

// インターフェース: a_n = sum_{i=1}^d c_i * a_{n-i}
ll solve_linear_recurrence(const vector<ll>& c, const vector<ll>& a, ll K) {
    int d = c.size();
    if (K < d) return a[K];

    // Q(x) = 1 - c_1 x - c_2 x^2 - ...
    vector<ll> Q(d + 1);
    Q[0] = 1;
    for (int i = 0; i < d; ++i) {
        Q[i + 1] = (MOD - (c[i] % MOD)) % MOD;
    }

    // P(x) = (A(x) * Q(x)) mod x^d
    vector<ll> P(d, 0);
    for (int i = 0; i < d; ++i) {
        for (int j = 0; j <= d && i + j < d; ++j) {
            P[i + j] = (P[i + j] + a[i] * Q[j]) % MOD;
        }
    }

    return bostan_mori(P, Q, K);
}
```

## 5. 計算量と手法の使い分け基準

| 手法                     | 計算量               | 適用条件・目安                                                                   |
| ------------------------ | -------------------- | -------------------------------------------------------------------------------- |
| **通常の行列累乗**       | $O(d^3 \log K)$      | $d \le 100$ 程度。グラフのパス数え上げなど、状態遷移自体が行列で与えられるとき。 |
| **Kitamasa法**           | $O(d^2 \log K)$      | $d \le 4000$ 程度。漸化式が既知の場合（多項式剰余が必要）。                      |
| **Bostan-Mori法 (愚直)** | $O(d^2 \log K)$      | $d \le 4000$ 程度。実装が極めて平易で定数倍が軽い。                              |
| **Bostan-Mori法 (NTT)**  | $O(d \log d \log K)$ | $d \le 10^5$ 程度。多項式乗算に NTT（高速フーリエ変換）を適用。                  |
