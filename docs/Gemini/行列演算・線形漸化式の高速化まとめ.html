線形漸化式・行列演算 高速化まとめ

低レイヤ最適化から Kitamasa法・Bostan-Mori法、つまずきポイントの完全整理

1. メモリ構造と低レイヤ最適化

競プロで頻出の $N \times N$ 行列積 $C_{i,j} = \sum_k A_{i,k} B_{k,j}$ を高速化するハードウェア寄りのアプローチです。

💡 なぜ vector<vector<T>> は遅く、array や静的配列は速いのか？
  • vector<vector<T>>（ポインタの配列）: 外側の配列が保持するのは「各行のベクトルのアドレス」です。データがヒープ上に散らばるため、mat[i][j] のアクセス時に 二重のポインタ参照 が発生し、キャッシュミスが多発します。
  • array<array<T, N>, N> / T mat[N][N]: 全 $N \times N$ 要素がメモリ上に 1つの連続ブロック として並びます。base + sizeof(T)*(i*N + j) という掛け算1発でアドレスが決まり、間接参照がゼロになります。

SIMD (Single Instruction, Multiple Data)

CPUが1つの命令で複数のデータ（例: 256bit レジスタで 64bit 整数なら 4 個、32bit 整数なら 8 個）を同時に並列計算する仕組みです。ループが連続メモリにアクセスしていれば、コンパイラが自動で SIMD 命令（AVX2等）に変換（自動ベクトル化）してくれます。

転置行列 $B^T$ を用意する理由

標準的な行列積では $B$ の「列方向（縦）」にアクセスするため飛び飛びになります。あらかじめ $B$ を転置しておくと、$A$ の行と $B^T$ の行という 「行同士（連続メモリ）の内積」 になり、SIMDロード命令（_mm256_loadu_si256 等）が綺麗にハマります。

2. 遷移行列とサイズ $d$ の壁

遷移行列 とは、「現在の状態ベクトル」に掛けることで「1ステップ先の状態」に進めるための正方行列です。

💡 遷移行列の具体例（フィボナッチ数列）
$$\begin{pmatrix} F_{n+1} \\ F_n \end{pmatrix} = \begin{pmatrix} 1 & 1 \\ 1 & 0 \end{pmatrix} \begin{pmatrix} F_n \\ F_{n-1} \end{pmatrix}$$ $K$ ステップ進めるには遷移行列を $K$ 乗すればよく、繰り返し二乗法で $O(d^3 \log K)$ で計算できます。

行列累乗の限界

漸化式の項数（状態数）が $d = 1000$ になると、行列の掛け算 1 回あたり $d^3 = 10^9$ 回（約10億回）の計算が発生し、TL（実行時間制限）に間に合いません。そこで **「巨大な行列を作らずに第 $K$ 項だけを直接求めるアルゴリズム」** が必要になります。

3. 2大高速化アルゴリズムの直感

① Kitamasa法：文字式の整理（$O(d^2 \log K)$）

ケイリー・ハミルトンの定理（$A$ は自身の固有多項式を満たす）を利用し、$A^K$ を計算する代わりに $x^K \bmod P(x)$ という多項式の剰余を計算します。

フィボナッチなら $A^2 = A + I$ を使って、$A^3 = 2A + I, \ A^4 = 3A + 2I \dots$ と、どんな高次項も常に「$d$ 個の係数（一次結合）」にまとめ直して計算を高速化します。

② Bostan-Mori法：母関数の縮約（$O(d \log d \log K)$ / $O(d^2 \log K)$）

母関数 $\frac{P(x)}{Q(x)}$ に対し、分母を偶数次の多項式に変形することで、求めたいインデックス $K$ を毎ステップ $K \leftarrow \lfloor K/2 \rfloor$ と半減させていく アルゴリズムです。

4. 母関数と有理化のカラクリ（つまずきポイント解説）

❓ 疑問1: フィボナッチの母関数で、引き算するとどうして $x$ だけが残るのか？
次数の列を縦に揃えて引き算を考えると一目瞭然です。 $$\begin{aligned} F(x) &= \mathbf{0} + \mathbf{1}x + 1x^2 + 2x^3 + 3x^4 + \dots \\ xF(x) &= \phantom{0 + } \mathbf{0}x + 1x^2 + 1x^3 + 2x^4 + \dots \quad \text{($x^1$の係数は $0$)} \\ x^2F(x)&= \phantom{0 + 0x + } 0x^2 + 1x^3 + 1x^4 + \dots \end{aligned}$$ 上から下の2行を引くと：
  • $x^0$ の項: $0 - 0 = 0$
  • $x^1$ の項: $1x - 0x = \mathbf{1x}$（$F(x)$ の $1x$ がそのまま残る）
  • $x^2$ 以降: すべて $F_n - F_{n-1} - F_{n-2} = 0$ となり相殺して消滅する
結果として $(1 - x - x^2)F(x) = x \implies F(x) = \frac{x}{1 - x - x^2}$ となります。
❓ 疑問2: なぜ $Q(-x)$ を掛けると偶数乗だけになるのか？
高校数学の 「ルートの有理化」 と同じ原理です。 $$(a - b)(a + b) = a^2 - b^2$$ $Q(x)$ と $Q(-x)$ を掛けると、符号が反転する奇数次の項がすべて相殺され、2乗された $x^2$ の項（偶数次項）しか残りません。

分母が $D(x^2)$ と偶数乗の塊になれば、分子 $P(x)Q(-x)$ のうち：
  • $K$ が偶数なら 偶数次の項 だけを取り出す $\to [t^{K/2}]$ の問題へ縮小
  • $K$ が奇数なら 奇数次の項 だけを取り出す $\to [t^{(K-1)/2}]$ の問題へ縮小

5. Bostan-Mori法 実装テンプレート (C++)

線形漸化式 $a_n = \sum_{i=1}^d c_i a_{n-i}$ と初期値から第 $K$ 項を求める完成版コードです。

#include <iostream>
#include <vector>

using namespace std;
using ll = long long;
const ll MOD = 998244353;

// 多項式乗算 (愚直 O(d^2) / NTTを使えば O(d log d))
vector<ll> multiply(const vector<ll>& A, const vector<ll>& B) {
    vector<ll> C(A.size() + B.size() - 1, 0);
    for (size_t i = 0; i < A.size(); ++i) {
        for (size_t j = 0; j < B.size(); ++j) {
            C[i + j] = (C[i + j] + A[i] * B[j]) % MOD;
        }
    }
    return C;
}

// Bostan-Mori法: [x^K] (P(x) / Q(x)) を求める
ll bostan_mori(vector<ll> P, vector<ll> Q, ll K) {
    while (K > 0) {
        // 1. Q(-x) を構築（奇数次の項の符号を反転）
        vector<ll> Q_neg = Q;
        for (size_t i = 1; i < Q_neg.size(); i += 2) {
            Q_neg[i] = (MOD - Q_neg[i]) % MOD;
        }

        // 2. 分母・分子に Q(-x) を掛ける（有理化）
        vector<ll> num = multiply(P, Q_neg);
        vector<ll> den = multiply(Q, Q_neg);

        // 3. Kの偶奇に応じて必要な項のみを抽出し、K を半分にする
        vector<ll> next_P, next_Q;
        for (size_t i = (K & 1); i < num.size(); i += 2) {
            next_P.push_back(num[i]);
        }
        for (size_t i = 0; i < den.size(); i += 2) {
            next_Q.push_back(den[i]);
        }

        P = move(next_P);
        Q = move(next_Q);
        K >>= 1;
    }
    return P.empty() ? 0 : P[0];
}

// 線形漸化式ソルバー
// a_n = c[0]*a_{n-1} + c[1]*a_{n-2} + ... + c[d-1]*a_{n-d}
ll solve_linear_recurrence(const vector<ll>& c, const vector<ll>& a, ll K) {
    int d = c.size();
    if (K < d) return a[K];

    // Q(x) = 1 - c_1*x - c_2*x^2 - ... - c_d*x^d
    vector<ll> Q(d + 1);
    Q[0] = 1;
    for (int i = 0; i < d; ++i) {
        Q[i + 1] = (MOD - (c[i] % MOD)) % MOD;
    }

    // P(x) = (A(x) * Q(x)) mod x^d
    vector<ll> P(d, 0);
    for (int i = 0; i < d; ++i) {
        for (int j = 0; j <= d && i + j < d; ++j) {
            P[i + j] = (P[i + j] + a[i] * Q[j]) % MOD;
        }
    }

    return bostan_mori(P, Q, K);
}
